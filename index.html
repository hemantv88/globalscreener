⚙️ RS Calculation Settings

Controls how the RS / MRS Rank columns and "Leading RS" are calculated. Changes apply to the tab you're currently viewing after clicking Apply.

Any ticker, in the same format the screener already uses (India: SYMBOL.NS, US/ETF: plain symbol). It has to be present in this market's tab of the Google Sheet — add it to the BENCHMARKS list in the Apps Script and re-run it first, or Apply will tell you it cannot be found.

RS is measured as excess return over this series, so the choice sets the bar: benchmarking against Nifty Smallcap 250 during a small-cap rally makes most of your universe read as weak, while Nifty 50 asks the broader "is it beating the market" question.
